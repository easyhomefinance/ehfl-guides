Get an AI valuation report in five steps, not a site visit.

Technical AI turns the property details you already have into a full desktop valuation — adopted market value, realisable and distress values, and a flag list for anything it couldn't confirm. Here's the whole flow, start to finish.

5Steps
~2 minAnalysis time
17Required fields
01

Open the loan, find the report tab

Inside any loan record, look at the left-hand menu. Under Loan Details, open Desktop Valuation Report — that's where Technical AI lives.

→The loan header at the top (loan #, status, ROI, tenure) stays visible the whole time — you're always working inside the correct loan file.
02

Fill in the property details

The Technical AI form asks for the property's address, survey details, and boundaries — the same information a physical valuer would need. Fields marked * are required.

→Applicant details and their KYC info stay pinned on the right, so you can cross-check the address against the borrower's documents as you type.
03

Submit for analysis

Once every required field is filled — including Property Boundaries and which type of valuation you need (Apartment only, or Plot and Construction) — click Send Data for Analysis.

04

Wait, then pull up the result

Analysis takes about 2 minutes. It doesn't run in the foreground — refresh the page and check Previous Analysis History at the bottom of the same screen, then click View Analysis.

→Every submission is logged here with its own Analysis ID, so past reports for this loan are never lost — and you can raise an appeal on any of them.
05

Read the report

The report leads with the number that matters — Adopted Market Value — plus realisable (90%) and distress (80%) values, then breaks down exactly how it got there: property identification, valuation approach, and the rates it used.

Watch for: flagged reports

A report can come back flagged for manual review before disbursement. That's the AI telling you it couldn't confirm something from what it was given — not an error.

  • In this example it's a CRITICAL flag: document type was never submitted, so it can't confirm this is a Sale Deed vs. an Agreement to Sell.
  • It also had no land rate for the area, so it fell back to the nearest branch's rate card.

Cleaner input in Step 2 — the right document type, an address the rate card recognises — means fewer flags and less manual review later.
